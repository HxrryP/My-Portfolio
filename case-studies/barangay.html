THE PROJECT

What this project
set out to do.

The project centers on making barangay transactions easier to organize and follow. Its published description identifies it as a web-based system intended to streamline transaction management.

  • One place for transactions

    The core idea is a shared view of requests and their progress.

  • Web-based workflow

    The project is described as a website built with PHP, a custom framework, and Bootstrap.

  • Clear stages

    A transaction system needs a way to show where a request stands; the sample preview illustrates this concept.

THE SAMPLE

See the idea
in action.

The interactive portfolio sample uses fictional reference numbers and three simple statuses. You can filter requests and advance them to see how a queue might feel to use.
